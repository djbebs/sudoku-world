# Crans-Montana Pixel Atlas V4

Independent map mini-project, published under the `crans-montana-pixel-atlas/` folder of the Sudoku World GitHub Pages repository. The Sudoku game itself is unchanged.

Open `index.html` for the illustrated map; use the `3D réelle` button to load `3d.html`, which streams official terrain and swissBUILDINGS3D data from swisstopo via CesiumJS. The 3D view needs a WebGL-compatible browser and an Internet connection.

If the 3D view is unavailable, the atlas returns automatically to the illustrated model. The illustrated map is artistic and not a geographic representation.

Data credits: © swisstopo, https://www.swisstopo.admin.ch/.

CESIUM library: CesiumJS 1.147.0, Apache-2.0.
