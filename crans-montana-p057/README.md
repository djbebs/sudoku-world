# P0.5.7 retirée du projet actif

Cette ancienne préversion utilisait des tracés reconstitués à partir d'une capture d'écran. Ils ont été jugés insuffisants et ne sont **plus utilisés ni distribués** dans la version courante du dépôt.

- Le fichier de traces GeoJSON a été supprimé du branchement actuel.
- La page P0.5.7 renvoie désormais vers P0.5.8.
- Pour la suite du projet, les surfaces et sentiers sont chargés depuis le service de mensuration officielle du Valais (couches 270 et 180), sans redessin à partir de captures d'écran.
- Les volumes des bâtiments et les arbres proviennent des couches officielles swisstopo.

**Important :** un extrait de données d'un service officiel n'est pas automatiquement un document cadastral juridiquement certifié. Pour une certification, il faut un extrait validé par l'autorité compétente ou un géomètre habilité.

Nouvelle version : https://djbebs.github.io/sudoku-world/crans-montana-p058/?v=1

Les anciens commits GitHub peuvent toujours être accessibles dans l'historique Git. Cette modification retire les tracés de la version publiée actuelle et ne réécrit pas l'historique du dépôt.
